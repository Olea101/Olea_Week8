Project Overview
This project demonstrates key Dart logic concepts, including conditionals, loops, functions, and exception handling (`try/catch`) using a grade processing system.

Features
Conditional Logic: Evaluates each score to check whether it meets the passing threshold (`>= 75`).
Loops: Iterates through a collection of raw score inputs.
Functions:Encapsulates calculation and processing logic into a reusable function returning summary results.
Error Handling & Bad Input Testing: Catches invalid non-numeric inputs (e.g., `'invalid_score'`) gracefully using a `try/catch` block to prevent program crashes.

How to Run the Code

Using DartPad (Web)
1. Open [DartPad](https://dartpad.dev/).
2. Copy the contents of `main.dart` from this repository.
3. Paste the code into the DartPad editor.
4. Click the **Run** button in the top right corner.
